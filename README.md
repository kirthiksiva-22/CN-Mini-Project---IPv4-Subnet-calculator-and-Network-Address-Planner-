# IPv4 Subnet Calculator and Network Address Planner

## 📌 About the Project

The **IPv4 Subnet Calculator and Network Address Planner** is a computer networking project designed to simplify IPv4 subnet calculations and network address planning.

The project focuses on fundamental networking concepts, including IPv4 addressing, subnet masks, CIDR notation, network addresses, broadcast addresses, and usable host ranges. It also explores subnet allocation using Fixed Length Subnet Masking (FLSM) and Variable Length Subnet Masking (VLSM).

The proposed application uses Python for calculation logic and Flask with HTML and CSS for the web interface.

## 🎯 Objectives

* Calculate IPv4 network addresses and broadcast addresses.
* Determine subnet masks from CIDR prefix lengths.
* Identify usable host ranges and address capacity.
* Understand and demonstrate FLSM and VLSM subnetting.
* Support systematic IP address allocation for different departments.
* Improve understanding of IPv4 subnetting through a user-friendly interface.

## 🛠️ Proposed Technology Stack

* **Programming Language:** Python
* **Web Framework:** Flask
* **Frontend:** HTML and CSS
* **Networking Module:** Python `ipaddress` module

## ⚙️ Key Features
